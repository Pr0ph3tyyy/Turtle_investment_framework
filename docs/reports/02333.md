### 3.1 模块一：资本消耗强度

**分析**：
1. **维持性资本投入高**：整车制造需持续更新产线、模具投资；研发支出连续3年超百亿元（2024年超104.5亿人民币≈116亿港元）
2. **无形资产持续累计**：无形资产2021-2025年从7,091→12,235百万港元（增长72%），反映专利/软件资本化支出持续投入
3. **Capex数据缺失**：Tushare港股限制，无法直接获取资本开支数据；但投资业务现金净额2025年为-29,154百万港元（含理财产品等），2024年为-23,296百万港元，规模庞大
4. **OCF相对净利润倍数高**：2025年OCF=40,355百万港元，远超净利润9,865百万港元，说明营运资本对现金有正贡献（预付/票据等占用供应商资金）；但扣除巨额投资需求后实际自由现金远不及OCF

**输出**：`capital-hungry`（修正初判，整车制造研发+产能双重投入，典型重资本消耗模式）

---

### 3.2 模块二：收款模式

**分析**：
1. **先货后款为主**：整车B2B经销商模式，先交货后收款；但公司对经销商有一定垄断地位（品牌授权），账期相对可控
2. **占用供应商资金强**：应付账款2025年达45,874百万港元，相比应收账款33,447百万港元高出约12,427百万港元；供应商为其提供大量商业信用
3. **收款比率分析**（§17.3）：2025年收款比率100%（应收账款减少），2024年93.94%，2023年95.75%——整体健康
4. **银行承兑汇票保证金**（受限现金3,137百万人民币）：说明部分应付账款以承兑汇票支付，反映强大的占用供应商资金能力

**输出**：`先货后款`，对现金状况整体为正贡献（占用供应商资金>占用经销商资金）

### 3.3 模块三：竞争格局与护城河

**市场结构**：垄断竞争（中国自主品牌SUV市场：比亚迪宋、吉利博越、长城哈弗等多强并立）

**第一层：非技术性护城河（商业壁垒）**

| 壁垒类型 | 评估 | 说明 |
|---------|------|------|
| 规模效应 | 中等，存在 | 年销约130万辆，产能规模提供一定成本优势，但不足以形成压倒性壁垒 |
| 网络效应 | 不存在 | 汽车行业无典型网络效应 |
| 转换成本 | 弱 | 汽车购买决策周期长，品牌忠诚度存在但消费者切换成本低 |
| 无形资产（品牌） | 中等，存在 | 哈弗在SUV细分市场具备较强品牌认知；坦克在越野细分的高端定位初步建立 |
| 成本优势 | 弱至中 | 国内制造成本低于合资品牌，但与比亚迪、吉利相比无明显优势 |

**第二层：技术性护城河（数据与算法壁垒）**

| 壁垒类型 | 评估 | 说明 |
|---------|------|------|
| 数据资产壁垒 | 不存在 | 汽车使用数据尚未形成可变现的数据闭环 |
| 核心算法/模型 | 弱，初步建立 | 三电系统、智驾算法自研比例超50%，Hi4/Hi4-T混动架构有一定技术壁垒，但距行业前沿（华为、比亚迪）仍有差距 |
| 履约/供应链系统 | 中等 | 全球供应链体系已建立（俄罗斯、南非、澳大利亚等），但尚未形成显著壁垒 |
| AI/前沿技术 | 弱 | 毫末智行自动驾驶投入，但IPO受阻反映商业化进展不及预期 |

**两层交互关系**：品牌壁垒（商业层）→ 规模销量 → 研发投入支撑（技术层），但反哺循环不够强。未形成复合护城河飞轮。

**定价权验证**：坦克品牌均价持续提升，魏牌均价突破25万元（同比+56.6%），局部细分市场有定价权；但哈弗品牌受价格战压制，主流产品定价受限。

**护城河侵蚀风险**：新能源渗透率约25.7%（行业均值40%），燃油SUV占比过高，存在结构性侵蚀风险。

**输出**：`中性`
- 护城河类型：[非技术] 品牌/规模效应（中等，SUV及越野细分）+ [技术] 混动技术体系（弱至中，Hi4系列）
- 复合护城河飞轮：否

### 3.4 模块四：周期性

**分析**：
- 汽车行业为弱至中等周期性：需求受宏观经济影响，但汽车更新需求相对刚性
- 5年收入波动：2021→2025年，最低136,405→最高222,824百万港元，波动幅度约63%（收入端）
- 归母净利润波动更剧烈：6,726→12,692→9,865百万港元，标准差约2,300百万港元，CV约28%
- 受新能源转型周期影响较大：燃油→电动结构性转型叠加行业整体"价格战"周期
- 当前位置：行业"价格战"阶段趋缓，2026年增速预期放缓（1%），处于周期**中段至高位**

**输出**：`弱周期`（汽车整体弱周期，但当前正处于新能源转型压力叠加，不确定性偏高）

### 3.7 模块七：监管与政策风险

**分析**：
- 2025年继续免征新能源车购置税；2026年起切换为减半征收，政策微收紧但非断崖

- 俄罗斯本地化制造（俄制造子公司持股75.51%）面临地缘风险

**输出**：`中性`（国内政策整体支持；海外政策风险中等，地缘摩擦为不确定因素）

## 八、风险提示与待验证事项
