    3.1 资本消耗强度（模块一）¶

    分析：

    • PPE账面值：FY2025 = 17,798M；FY2024 = 17,113M；FY2023 = 19,709M；FY2022 = 12,941M
    • 真实Capex（来自WebSearch年报数据）：2024年 = 3,918.94M RMB；D&A 2024年 = 3,159.50M RMB
    • Capex/D&A = 3,918.94/3,159.50 = 1.24x（资本开支略高于折旧，处于扩张状态）
    • FY2023年净PPE增加 = 19,709 − 12,941 = 6,768M，叠加折旧侵蚀，实际购置接近9,000-10,000M（与§5投资活动CF-17,735M部分吻合）
    • 年收入约177,000-179,000M，Capex约3,900-10,000M（依年份不同），Capex/收入约2-6%
    • 组装制造业维持竞争力需要持续更新设备、建设厂房，且需配合客户产品迭代追加智能制造设备

    判断：capital-hungry 依据：①PPE资产规模庞大（17,798M RMB），相当于归母净利润的5.1倍；②Capex/D&A>1.2x，持续资本再投入；③EMS行业低利润率（净利率<2%）意味着自由现金流薄弱，资本扩张依赖外部融资（2023年大幅举债扩产）

    3.2 收款模式（模块二）¶

    分析：

    • 应收账款（FY2024末）= 32,306.02M RMB（P3，毛额32,399.26M，净32,306M）
    • 应收账款（FY2025末）= 14,999.04M RMB（§4，大幅下降）
    • 账龄结构（FY2024，P3）：90天内98.2%，91-180天1.8%，几乎无180天以上账款 → 客户信用质量高
    • 最大客户占AR 49%（苹果），前五大合计61%（P3）
    • 关联方应收（FY2024末）= 8,173.75M RMB，占净AR 25.3%；FY2025H1 = 5,405.91M，占31.4%（⚠️ 集中风险上升）
    • 典型时间线：接单→生产（30-60天）→交货→开票→收款（30-60天），总垫资周期60-90天
    • 应付账款（FY2024末）= 35,331.18M，FY2025H1 = 27,100.65M；应付 > 应收，占用供应商资金

    判断：先货后款（占用供应商资金型） EMS行业典型：收款慢于付款，但通过强势压应付账款账期（90天以内为主），整体对供应商形成资金占压，对公司现金流有正贡献。然而关联方应收账款占比上升（31.4%），需注意集中信用风险。

    3.3 竞争格局与护城河（模块三）¶

    市场结构：垄断竞争（少数几家大型EMS企业+众多小厂，富士康绝对龙头，其余激烈竞争）
