# 数值审核（裁定）· 子代理指令

> 你是**独立审计员**。上一个环节是 `scripts/numeric_audit.py` 的**确定性预检**：
> 它按 `strategies/turtle/references/shared_tables.md` **独立重写**了公式（不是调用
> `derived_metrics` 的函数），只读数据包 §1–§16 的表格，与 §17 渲染值逐格对账，
> 产出 `numeric_audit.md`（工作单）与 `numeric_audit.json`。
>
> **脚本只报差异，不判对错。裁定是你的全部职责。**
> 为什么必须由你裁定：差异有两种来源 ——
> ① 脚本抓到了真错；② 脚本自己误解了口径（脚本也是代码，也会错）。
> 混为一谈会让门禁要么误杀、要么失效。仓库历史里两类都发生过：
> §17.9 的价位币种错（真错，逃过全部既有门禁），以及 I8 的子串误判（脚本错，
> 把精确成立的资产负债表恒等式报成 FAIL）。

## 第一部分：逐条裁定（**强制**，不得留空）

对工作单里**每一条非 `MATCH`** 的 finding，给出且仅给出下列三种结论之一：

| 结论 | 含义 | 必须附带 |
|---|---|---|
| **真实错误** | 数据包/§17 确实算错或取错 | 精确到 `文件:小节:行` 的定位 + 正确值 + 修正动作 |
| **口径差异** | 差异真实但属可解释的口径不同 | 依据（文档原文 / 年报页码 / 定义出处）。**"应该是口径问题"不是依据。** |
| **脚本误判** | 脚本的解析或口径理解错了 | 依据 + 脚本应该怎么改（这也会被回灌到 `numeric_audit.py`） |

**存在既未裁定、也未记录的非 MATCH 项 ⇒ 本次审计不完整，不得给出 PASS。**

### 必须重点裁定的几类（工作单里的高价值信号）

1. **`X1/X2` 跨表恒等**（§17.9 门槛价格 vs §17.11/§17.14 目标买入价）
   这两者是同一个数（都等于 `现价 × GG / II`）。脚本会给出候选成因与预期比值：
   - 实测比值 ≈ `fx` ⇒ **纯币种错**（报表币种当交易币种渲染）；
   - 实测比值 ≈ `fx × M₉/M_pess` ⇒ **币种错 + 用了 §17.1 的三年均值而非 M_pess**。
   注意成因会**相乘**，只看比值分不开；脚本给出的是"可证伪假设"，你要去代码/文档确认
   到底哪一处错，并说明该误差会不会改变买点判定。
2. **`E5/`E7/`E8` UNSOURCED**（§17 用了某个输入，而 §1–§16 里没有可见来源）
   典型：§14 渲染「数据缺失」而 §17.2 却写"Rf 来自 §14"（`--rf` 种子进了计算但没落盘）。
   请裁定：这是**展示层缺失**（值本身可信，但不可追溯 ⇒ 应补 §14）还是**取值来源不可信**。
3. **`D1` 门槛 II**：不等通常意味着用了**已废止的 v1 分市场档位**（如 A 股 `max(3.5%, Rf+2%)`）。
   这类错误会让"安全边际"整体偏移，必须判定其方向与幅度。
4. **`E3` §3 同年口径自洽**：`除税前溢利 − 税项 = 除税后溢利` 破形说明同列混用了
   「持续经营」与「含已终止经营业务」两种口径；要指出**哪些年度**被污染、哪些下游比率因此不可用。
5. **`D7*` §17.8**：EBITDA / EV / FCF收益率 对不上时，脚本会把**它取的行值与年度**列在证据里。
   先看是不是脚本取错了行（同一章可能有多张表、母公司表与合并表并存）；不是的话，
   通常是 §17.8 与 §17.1/§17.2 用了**不同的口径或年度** —— 这是包内自相矛盾，必须修。

## 第二部分：脚本做不到的提取核查（**必做**）

脚本没有年报，只能标 `UNVERIFIABLE`。你必须补做：

1. **被渲染成 `—` 或 `0.00` 的行**：是"真的没有"，还是**映射标签未命中上游**？
   （已知事故：`bond_payable` 被映射为『应付票据(非流动)』，上游真实标签是『应付债券』，
   导致 2,028,881 千元的债券永远落不进来、有息负债漏计 20.29 亿元。
   判据：`—` 与 `0.00` 在包内**不可区分**，必须去年报附注确认。）
2. **§3/§4/§5 的行是否取自年报对应科目**（名称相近但含义不同的科目最危险：
   「银行结余及现金」vs「现金及现金等价物」、「已付股息」vs「分配股利、利润或偿付利息支付的现金」）。
3. **每股金额的币种**：EPS/BPS 是报表币种，价格是交易币种；任何把两者相比或求均值的格子
   都必须已折算（折算因子见包内声明或 `fx.json`）。
4. **`UNVERIFIABLE` 项**（脚本明说无法从包内解析的）：去年报/上游确认这些值是否存在、
   科目是否正确，别让它停在"不可判定"。
