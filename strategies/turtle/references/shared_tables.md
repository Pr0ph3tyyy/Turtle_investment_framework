## 支付率计算规则

```
支付率 = 年报同币种计算：各财年股息总额(报表币种) / 归母净利润(报表币种)
数据来源：data_pack_market §6 股息历史 + §3 归母净利润

⚠️ 禁止使用 yfinance 的 payoutRatio、dividendRate、trailingEps 字段
⚠️ 必须使用同币种数据（报表币种股息 / 报表币种利润）

支付率序列：过去3~5年逐年计算
支付率均值 M = 近3年均值
支付率锚定值 = 承诺支付率（若有明确承诺）；若无承诺则使用 M（近3年均值）

注销型回购 O = 过去3年年均注销型回购金额（百万元），来源 §15
稀释净效果 = 回购减少股本 − 新发行增加股本
```

## 穿透回报率公式

```
港股：
  穿透回报率 = [基准值 × 支付率锚定值 × (1 − Q%) + O] / 当前市值

A股（长期持有，Q=0）：
  穿透回报率 = [基准值 × 支付率锚定值 + O] / 当前市值

其中：
  因子2 基准值 = C（归母净利润，报表口径）→ 输出 R%
  因子3 基准值 = AA（真实可支配现金结余）→ 输出 GG%

⚠️ 税基差异说明：
  因子2 对报表利润 C 征税（粗算，快速近似）
  因子3 对真实可支配现金 AA 征税（精算，保守底线）
  两者偏差 HH = R − GG 是粗算/精算方法论差异的正常结果
  HH 通常在 1-3 pct 范围内；若 |HH| > 3 pct 需调查成因
```

## 门槛值 II 计算公式

**全市场统一口径：`II = max(5%, Rf + 3%)`**（2026-10-13 确定，A股/港股/美股一致）。

**唯一来源**：`scripts/tushare_modules/constants.py` 的 `II_FLOOR = 5.0` / `II_SPREAD = 3.0`
与 `ii_threshold()`。§17.2 / §17.9 / §17.11 一律经 `TushareClient._get_rf_ii()` 取值，
**不得在别处重写 max() 公式**（此前三处重复实现，美股档位还与文档矛盾 —— `known_issues.md` P1-12）。

```
Rf = data_pack §14 无风险利率
II = max(5.0%, Rf + 3.0%)        # 不分市场

示例：Rf = 1.67%  → II = 5.00%（下限生效）
      Rf = 4.20%  → II = 7.20%（浮动项生效）
```

### 为什么统一取最严档

方法论来源自身**矛盾且不完整**，无法支撑分市场档位：

| 市场 | 文档原文 | 出处 |
|---|---|---|
| A股 | 「最少有 3%」 | 因子2 `[1:34:10]` |
| A股 | 「股息率至少要四个点」 | 因子2 `[44:06]` |
| A股 | 唯一算例用 **4%**（五粮液 4459 亿 = 悲观利润×0.7÷4%，已复算吻合） | 因子2 `[45:29]` |
| 港股 | 「最少在 4% 以上，最好都在 5%」 | 因子2 `[1:34:10]` |
| 美股 | **未定义** | — |
| 共同 | 「至少要大于货币的无风险利率 1%」 | 因子2 `[1:34:41]` |

→ 项目决定：**取「港股最好档 5%」为下限、`Rf + 3%` 为浮动项，三市场一致适用**，
消除市场间档位漂移。

> ⚠️ **这是一次刻意的收紧**，不是文档原样：按文档档 A股会是 `max(3%, Rf+1%)`（明显更松），
> 港股 `max(4%, Rf+1%)`。收紧后 `GG − II` 更容易为负，即整体判定更保守。
> 若要放宽，只改 `constants.py` 的 `II_FLOOR` / `II_SPREAD` 两个常量，无需碰任何公式。

## 跨币种处理规则

穿透回报率公式中所有项必须使用同一币种：

```
基准币种 = data_pack_market 报表币种（§头部标注）

- 报表币种 = HKD → 市值用港元市值（§1 直接取值）
- 报表币种 = USD → 市值用美元市值（§1 直接取值）
- 报表币种 = CNY 但股价为 HKD：
    市值 = 港元市值 / 汇率（取 §1 或 data_pack 头部汇率）
    转换为人民币市值后计算
- 报表币种 = CNY 但股价为 USD：同理，使用汇率转换

⚠️ 禁止混用：如用人民币利润除以港元市值（可导致 5-10% 计算偏差）
```
